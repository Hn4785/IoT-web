# Tài liệu bàn giao

Bản bàn giao cập nhật được gửi riêng, không commit hoặc push lên Git.
Repository chỉ giữ source, cấu hình mẫu và docs kỹ thuật để tái tạo ứng dụng.

File `AgriSense-Ban-giao-v1.0.docx` đã được phát hành ở lượt trước, không được
cập nhật trong đợt này. Bản đó là tài liệu cũ, không thay thế bản bàn giao gửi riêng.
