## Delivered

- Added `GET /api/v1/stations/:stationId/data/latest` for authenticated Admin and
  Farmer users. Client Developer Bearer access remains forbidden.
- Resolved station access through the database before contacting the Weather API;
  unknown and out-of-scope stations return the same safe `404 NOT_FOUND`.
- Added strict selection for the eight approved soil fields. Empty, duplicate,
  unknown and malformed query values return `400 VALIDATION_ERROR`.
- Normalized Weather API data into the frontend DTO without exposing upstream
  envelopes, credentials or guessed hardware metadata.
- Added bounded caching, request coalescing and stale-if-error behavior. HTTP
  responses remain `Cache-Control: no-store`.
- Kept field units, sensor IDs and depth unconfirmed until device metadata is
  available.
