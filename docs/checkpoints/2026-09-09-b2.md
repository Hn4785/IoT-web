Date: 2026-09-09

## Verified contract

- Frontend calls `GET /api/v1/stations/:stationId/data/latest` through the
  authenticated browser client.
- Optional fields are sent as one comma-separated value in caller order.
- The adapter supports all eight approved soil fields and preserves per-field
  timestamps, quality, nullable unit, sensor ID and depth.
- Cache and stale flags are preserved. No unit, device identity, farm, plot or
  timestamp is invented by the frontend.
- The frontend consumes only the normalized backend envelope; it does not call
  the raw Weather API or use an upstream API key.
