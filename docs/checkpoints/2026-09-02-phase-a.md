## Frontend-ready contract

The backend now provides the complete Phase A boundary needed to replace frontend mock
authentication:

- login, current user, mandatory first password change, refresh rotation and logout;
- exactly three roles: Admin, Farmer and Client Developer;
- one transferable Super Admin authority for administrator-account management;
- Admin user list/detail/provision/update/password-reset endpoints;
- Farmer-to-farm membership and Client-Developer-to-station grant endpoints;
- one-time, hashed, scoped, expiring, rotatable Client Developer API keys;
- live database-backed role/status/scope checks, normalized errors and request IDs;
- development OpenAPI at `/docs` and `/docs-json`.

Client Developer remains API-only and does not require a dedicated frontend page. The
frontend Admin area does require an account-management page that consumes the Admin user,
scope and Super Admin transfer contracts.
