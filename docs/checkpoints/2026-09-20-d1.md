# Checkpoint D1 — Audit and operational signals

Date: 2026-09-20  
Status: Verified locally; not committed or pushed

## Accepted behavior

- `GET /api/v1/admin/audit-events` is Bearer-protected and restricted to the
  current Super Admin. Admin, Farmer and Client Developer receive `403`.
- Audit results are newest-first, cursor-paginated and filter-bound. Stored
  metadata is projected through a flat safe allowlist; legacy arbitrary JSON and
  credential-like fields are not returned.
- `GET /api/v1/health` remains dependency-free liveness.
- `GET /api/v1/readiness` performs a one-second bounded PostgreSQL probe. Failure
  returns safe `503 DATABASE_UNAVAILABLE`; database details never enter the body.
  Concurrent checks share one in-flight query so a stalled database cannot create
  an unbounded probe backlog.
- Non-test runtime HTTP logs are JSON and contain only event, request ID, method,
  status and safe error code. Authorization, cookies and API keys are redacted.
- The in-process registry uses finite labels for HTTP/auth outcomes, database and
  Weather failures, evaluator runs and in-app notification delivery outcomes.
  It has no public transport at this checkpoint.

## D1 failure and leakage evidence

- Database reject and stalled-probe cases are deterministic tests.
- Liveness is verified not to execute the database probe.
- Audit role matrix covers unauthenticated, Admin, Farmer, Client Developer and
  Super Admin callers.
- Audit metadata, structured error logs and metric snapshots are asserted not to
  contain injected secret markers, upstream URLs, station IDs or raw API paths.
- Weather status/schema failures remain safe and increment only the finite
  `weather` dependency label.

## Deferred production decisions

- No metrics endpoint is exposed until ingress/TLS and scraper-network ownership
  are approved.
- Multi-instance deployment still needs shared/gateway rate limiting and a
  metrics aggregation strategy.
- Audit database-role append-only enforcement, backup/restore rehearsal and
  MFA/SSO remain OP-4 or launch hardening work.
